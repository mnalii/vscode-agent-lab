# 🎲 Soc Ops

### *Break the ice. Build with AI. Ship something fun.*

**Soc Ops** is a social bingo game for in-person mixers — AND a hands-on **VS Code Agent Lab** that teaches you how to build with AI agents in under 1 hour.

## ✨ What You'll Build

- 🎨 **A fully customized bingo game** — redesign it with any theme, any style
- 🤖 **AI-powered workflows** — custom agents, background tasks, cloud coding
- 🚀 **Auto-deployed web app** — live on GitHub Pages with every commit
- 🎓 **Real-world AI engineering skills** — context engineering, agentic primitives, TDD with agents

## 🎯 Why This Lab?

This isn't just about building a bingo game. It's about learning to:

- ⚙️ **Engineer context** for AI that actually understands your codebase
- 🔄 **Orchestrate agents** for parallel, isolated, and specialized tasks
- 🎨 **Design with AI** that breaks free from generic patterns
- 🧪 **Test-driven development** with AI writing AND implementing tests
- 📦 **Ship real products** using the full AI-first workflow

## 🚀 Quick Start

**Prerequisites:** [Node.js 22+](https://nodejs.org/) · VS Code 1.107+ · GitHub account

```bash
# Clone and run
npm install
npm run dev
```

**Want the full workshop experience?**

👉 **[Follow the Lab Guide](.lab/GUIDE.md)** — 1-hour guided workshop with custom agents, cloud coding, and TDD workflows.

## 🛠️ What's Inside

- **React 19** + **TypeScript** + **Tailwind CSS v4**
- **Vite** for lightning-fast dev experience
- **Vitest** for testing
- **Custom agents** for quiz generation, TDD workflows, pixel-perfect design
- **GitHub Actions** for automatic deployment

## 📚 Learning Path

The lab teaches you to master AI-assisted development:

1. **Context Engineering** → Guide AI with instructions, prompts, and agents
2. **Design-First Frontend** → Build beautiful UIs that break AI aesthetic patterns  
3. **Custom Quiz Master** → Create specialized agents for your workflows
4. **Multi-Agent Systems** → TDD, design reviews, parallel exploration

## 🎓 Workshop Outcomes

After completing this lab, you will:

- ✅ Onboard AI to your codebase with context engineering
- ✅ Understand agentic primitives for AI-first workflows
- ✅ Scale exploration and speed up learning across development tasks
- ✅ Ship a fully customized, working web app

Automatically deploys to GitHub Pages on every push to `main`:

```bash
npm run build    # Creates production build
git push         # Triggers deployment
```

Your live app: `https://{username}.github.io/{repo-name}`
